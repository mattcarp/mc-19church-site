# 19 Church Street

Static record of the Gozo house, linked from Island Commute. This site is currently served by GitHub Pages from `main` at the repository root; Island Commute itself is on Hetzner. HTTPS is enforced.

To update a photograph, add its asset and update `index.html` with accurate dimensions and alt text. Keep portrait photographs uncropped. Preview with `python3 -m http.server --bind 127.0.0.1 8848`, check at 375/768/1440, review, then commit only the intended paths and push to `origin main`. Verify the Pages build and the actual public page and image after publishing. Do not broadly stage `assets/` or publish private files.

Lead photograph: `assets/02-hallway.jpg` (1500×2000; converted from the PNG Matt supplied on 4 November 2026, kept in git history). Both portraits display uncropped. Additional interior photographs are still pending.
